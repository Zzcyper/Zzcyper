## Featured Projects

### [Secure Auth API](https://github.com/Zzcyper/secure-auth-api)

Production-style authentication backend built with FastAPI.

Includes JWT authentication, refresh tokens, email verification, password recovery, role-based permissions, rate limiting, PostgreSQL support, Docker, and automated tests.

`Python` `FastAPI` `SQLAlchemy` `PostgreSQL` `JWT`

---

### [ZnLookup](https://github.com/Zzcyper/roblox-user-lookup)

Web application for looking up public Roblox profiles and account information through Roblox APIs.

Includes profile data, social statistics, groups, games, badges, recent searches, and a JSON API.

`Python` `Flask` `Bootstrap` `JavaScript` `Roblox API`

---

### [IP Geolocation Lookup](https://github.com/Zzcyper/ip-geolocation-lookup)

Responsive Flask application for retrieving geolocation and network information from IPv4 addresses.

Includes validation, API error handling, ISP information, coordinates, timezone data, and map integration.

`Python` `Flask` `JavaScript` `REST API`

---

### [IP Address Lookup](https://github.com/Zzcyper/ip-address-lookup-cli)

Desktop network utility built with CustomTkinter for viewing public IP, local IP, geolocation, ISP, organization, timezone, and coordinates.

`Python` `CustomTkinter` `Networking`

---

### [Tic-Tac-Toe AI](https://github.com/Zzcyper/tic-tac-toe-ai)

Browser-based Tic-Tac-Toe game featuring multiple AI difficulty levels.

Hard difficulty uses Minimax with alpha-beta pruning to calculate optimal moves.

`Python` `Flask` `JavaScript` `Minimax`
